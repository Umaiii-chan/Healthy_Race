# Controles

Healthy Race é para dois jogadores no mesmo teclado.

| Ação | Jogador 1 | Jogador 2 |
| --- | --- | --- |
| Andar | `A` / `D` | `←` / `→` |
| Pular | `W` ou `Espaço` | `↑` |

| Ação geral | Tecla |
| --- | --- |
| Pausar / voltar | `Esc` |
| Mostrar rótulos de depuração na fase | `F1` |

## Dicas

- **Alavancas** são acionadas encostando nelas.
- **Elevador:** fique em cima da plataforma e ele sobe sozinho. Se o outro jogador estiver
  subindo, espere: o elevador volta quando fica vazio.
- **Pulo com tolerância:** dá para pular um instante depois de sair da beira e apertar o
  pulo um instante antes de pousar.
- Os controles estão em `Assets/_Game/Input/HealthyRaceInputActions.inputactions`.
